---
title: "RevenueCat Setup Guide"
description: "Connect iOS, Android, and web in-app subscriptions from RevenueCat to Indic8."
---

Connect RevenueCat to stream mobile in-app purchase events, trial conversions, renewals, and cancellations into Indic8.

## What You Need

| Item | Where to get it | Purpose |
| :--- | :--- | :--- |
| **Indic8 Webhook Ingress URL** | Indic8 Dashboard > Settings > Integrations > RevenueCat | The webhook listener URL |
| **Authorization Token** | Generated inside Indic8 settings modal | Verifies the request came from your RevenueCat project |

---

## Step 1: Get Ingress URL & Token from Indic8

1. In your [Indic8 Dashboard](https://app.indic8.ing), go to **Settings > Integrations**.
2. Click **RevenueCat**.
3. Copy both:
   - **Webhook URL**: `https://api.indic8.ing/v1/webhooks/revenuecat/whk_live_xxxxxxxx`
   - **Authorization Token**: A unique secret token string generated for your project.

---

## Step 2: Add Webhook in RevenueCat

1. Open your [RevenueCat Dashboard](https://app.revenuecat.com).
2. Select your App Project.
3. In the left navigation, click **Project Settings** (gear icon).
4. Click **Integrations** in the submenu, then select **Webhooks**.
5. Click **+ Add Webhook** or **New Integration**.

---

## Step 3: Fill in Webhook Settings

| Field Name | What to enter |
| :--- | :--- |
| **Webhook URL** | Paste the Indic8 URL from Step 1 |
| **Authorization Header Value** | Paste the Authorization Token from Step 1 |
| **Environment** | Check **Production** (you can also check **Sandbox** for test mode) |
| **Send Test Events** | Yes |

Click **Save** in the bottom right corner.

---

## Step 4: Event Mapping Summary

RevenueCat sends standard events that Indic8 categorizes automatically:

| RevenueCat Event | How Indic8 counts it |
| :--- | :--- |
| `INITIAL_PURCHASE` | Added as a new sale and updates MRR |
| `RENEWAL` | Realized recurring revenue (tracked on schedule) |
| `PRODUCT_CHANGE` | Plan upgrade or downgrade adjustment |
| `CANCELLATION` | Marked as scheduled cancellation |
| `EXPIRATION` | Deducted from active subscribers and MRR |
| `BILLING_ISSUE` | Past-due notice alert |

---

## Step 5: Verify Setup

1. In RevenueCat, click **Send Test Event**.
2. Select `INITIAL_PURCHASE`.
3. Open your Indic8 Live Feed to confirm the test transaction appears.
