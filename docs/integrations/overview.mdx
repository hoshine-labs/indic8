## Connection Models

Indic8 supports two connection mechanisms depending on provider capabilities:

### 1. Real-Time Webhooks (Recommended)
Webhooks provide sub-2ms event delivery directly when a transaction occurs in your gateway. Indic8 verifies incoming signatures using your provider webhook signing secrets.

### 2. Historical Backfill (Read-Only API)
When connecting a gateway for the first time, you can provide a **Restricted Read-Only API Key**. Indic8 automatically paginates through historical transactions to build historical MRR and cohort vintage charts without write access to your billing engine.

## Security and Permission Scopes

<Note>
  Indic8 **never** requests write permissions to your payment gateways. Always use restricted, read-only tokens with minimal scopes.
</Note>

| Provider | Recommended Key Type | Required Scopes |
| :--- | :--- | :--- |
| **Stripe** | Restricted API Key (RAK) | `Charges (Read)`, `Subscriptions (Read)`, `Invoices (Read)` |
| **Polar** | Personal Access Token | `Read-only` |
| **RevenueCat** | V2 REST API Key | `Read Project Data` |
| **Lemon Squeezy** | API Key | `Read Orders`, `Read Subscriptions` |
| **Apple App Store** | App Store Connect API Key | `Finance (Read)` |
| **Google Play** | Service Account Key | `Financial Reports (View)` |
